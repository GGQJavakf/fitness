# 原创金渐层猫静态动作分解图

本目录是训练页实际打包使用的静态动作素材。47 个动作全部使用同一只已确认的金渐层猫教练：圆脸大绿眼、金色细致毛发、奶油色口鼻和胸腹、深森林绿色头带与护腕、深色环纹尾巴，以及一致的拟人身体比例。

## 素材与版权边界

- 角色母版与动作源图均为本项目原创素材，不复制、描摹或复用“阿柴健身日记”等第三方角色、网络表情、真人动作视频、白色 3D 人体或其他受保护素材。
- 本运行时素材包不包含第三方动作素材，也不再保留第三方真人动作改编文件。
- 训练运行时不使用 GIF、动态 WebP、MP4、WebM、3D 人物或 AI 连续帧。每个动作只打包 2～4 张 JPEG 静态关键姿势。
- 普通动作默认 3 张；死虫式和鸟狗式因对侧伸展路径提供 4 张；平板支撑按动作性质提供 2 张。
- 同一动作的各阶段来自同一张高质量静态动作源图；卧推来自同一组已确认的完整静态关键帧，保持视角、角色比例、器械尺寸和画风一致。
- 猫教练图片属于品牌化动作步骤插画，不作为人体解剖或生物力学证明；动作执行应以 `rule-config/validated/exercises-v1.json` 中的中文步骤与安全提醒为准。正式公开发布前仍需健身专业人员逐动作复核。

## 生成与包体

- 用户确认的角色设定、静态动作源图和卧推静态关键帧位于 `assets-source/exercise-guides/`。
- `assets-source` 只作为构建输入，不在 `src` 下，因此不会进入小程序包。
- `scripts/build_static_exercise_guides.py` 从已确认静态源图裁取关键姿势，输出 256 × 256 JPEG、`static-manifest.json` 和 TypeScript 静态导入映射。
- 每张运行时图片不超过 40 KiB；构建和测试会检查阶段数、哈希、格式、动态媒体残留和可重复生成。

重建命令：

```powershell
python scripts/build_static_exercise_guides.py
```
