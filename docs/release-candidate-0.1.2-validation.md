`0.1.2` 已达到可复现的技术发布候选状态，但**尚不具备公开发布资格**。自动化门禁、关键页面模拟器检查和一次性空 MySQL 8 打包验证均已通过；公开内容专业审核和微信真机弱网恢复矩阵仍是外部门禁。该结论不代表生产部署、微信平台提审或公开发布完成。

## 安全与环境说明

外部 MySQL 端点的证书链无法在当前 JDK 信任库中完成身份校验。本次验证依据项目既有、明确记录的风险接受，仅对获批的一次性空验证 schema 使用加密但不校验证书身份的连接；因此该结果证明 MySQL 8 兼容性、迁移和打包运行，不证明端点身份或抗中间人能力。生产或长期环境必须使用可信 CA 的 `VERIFY_CA`/`VERIFY_IDENTITY`。

## 保持失败关闭的门禁

### 公开内容审核

`npm run preflight:release` 当前按预期阻断 7 类汇总项：

- 3 份内容仍为 `AI_VALIDATED`，不是健身专业人员批准；
- 3 份内容未激活 `public` 发布环境；
- 78 条动作替代关系尚未获得专业批准。

审核材料已生成至 `docs/public-content-professional-review-pack.md`，审核人、资质、日期、逐项结论和签署引用均保持空白。自动化、AI 或开发者检查不得代填这些字段。

### 微信真机弱网恢复

自动预览已生成，但手机端自动化在等待设备连接时超时，尚未获得物理设备证据。以下场景仍需按 `docs/device-debug-runbook.md` 在真实微信中执行并记录：

- 登录和计划加载超时/重试；
- 训练草稿恢复与最新持久状态保留；
- 记录组、保存和响应丢失后的幂等恢复；
- 弱网、断网、飞行模式、锁屏、杀进程和连续点击。

在设备型号、系统/微信/基础库版本、候选版本、时间、预期和实测结果完整记录前，不得宣称真机门通过。

## 可复现命令

```powershell
Set-Location miniprogram
npm ci
npm run verify
npm run preflight:staging
npm run preflight:release # 公开审核未完成时预期退出码为 2

Set-Location ..\backend
.\mvnw.cmd clean verify

Set-Location ..
git diff --check
git status --short
```

外部 MySQL 验证仅可使用明确授权的非生产一次性空 schema，并通过本地密钥注入；不得把连接串、用户名或密码写入仓库或验证日志。

## 回滚

候选尚未推送或发布时，可按提交边界回退；计划编辑器改动只涉及表现层状态、样式和回归测试，不修改已存计划语义。任何公开审核元数据更新必须由专业审核证据驱动并单独复验。
